# 个人主页生成与更新

## 第一次使用

- 给出 `assets/demo.html` 的预览。用户已经提供资料时，直接生成个人版。
- 用户还没有提供资料时，直接告诉他们：

  > 把你想放到个人主页上的资料发给我，我会直接生成一版给你预览。目前可展示四个区块：个人介绍、个人经历、作品与项目、联系方式。每个区块都支持文字、图片和超链接。简历、几段文字、照片、链接都可以直接发，手头有什么就先发什么。有新内容也可以在预览后继续加。

- 将用户资料整理为主页项目下的 `content.json`，参照 [资料格式](references/content.md)。直接使用用户给出的事实，缺失的内容留空。只显示有内容的区块，导航随之更新。需要参考版式时，可同时给完整的虚构示例。
- 仅将用于主页的图片复制到主页项目的 `media/`。用相对路径引用素材。联系信息只纳入用户希望展示的渠道。
- 从 Skill 目录运行 `python3 scripts/build.py /绝对路径/主页项目`。将生成的 `index.html` 作为预览交付。帮助用户打开预览，核对手机排版、导航、图文和链接。

## 更新主页

- 找到同一个主页项目，读取 `content.json`。只修改用户指定的内容，保留其他资料、模块 ID 和关联素材。
- 加模块时在 `sections` 的对应位置插入一项。文字、图片、链接可依用户顺序混排。改顺序时移动对应模块。
- 重新生成同一个项目里的 `index.html`，检查这次修改涉及的内容并交付新版预览。

## 发布或更新在线版本

- 预览完成后，根据用户的发布意图继续。先确定目标网址或平台，以及访客范围。用户已指定的发布方式和范围直接沿用。
- 查阅 [发布说明](references/publish.md)。根据用户已有账号、站点和当前 Agent 可用能力选择路线，必要时列出可用选项。已有站点时优先更新原站点。
- 只发布生成后的 `index.html`。图片已内嵌，外部图片仍按原地址加载。主页项目的编辑资料和未使用图片留在项目中。
- 能代发时，使用当前环境可用的账户和工具。缺少发布能力时，给出生成文件、所选平台的上传入口和简短操作步骤。
- 发布后用符合访问范围的身份验证正式链接能打开。将平台、项目标识、正式网址和访问范围记录到主页项目的 `deployment.json`，供之后更新使用。凭据由托管平台或当前环境管理。
